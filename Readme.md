# 🤖 Bot de Trading por Telegram

Bot de paper trading con precios reales de CoinGecko (gratis, sin API key).

## Comandos

| Comando | Descripcion |
|---|---|
| /search bitcoin | Buscar moneda y ver su ID |
| /price bitcoin | Precio actual |
| /chart bitcoin 7 | Grafico de 1/7/30/90 dias |
| /alert bitcoin up 5 | Alerta si sube 5% |
| /alert bitcoin down 10 | Alerta si baja 10% |
| /alert bitcoin any 3 | Alerta si se mueve 3% |
| /alerts | Ver alertas activas |
| /delalert bitcoin | Borrar alerta |
| /buy bitcoin 100 | Comprar con 100 USD |
| /sell bitcoin | Vender posicion |
| /portfolio | Saldo y posiciones |
